## The Story Files

This Directory contains all the story files. In other words, this
directory has all the actual descriptions and stuff.

## The Protocol

The protocol here is simple.

* There are Directories for each Room.
* There are subdirectories for each sub-situation.
* At the bottom level, there is a file called "skeleton.yaml".
* Rename the file to either "roomnumber-room.yaml" or
  "roomnumber-room-minority.yaml" and fill it with the information.
  Example: use "first-room" or "third-room-hindu".
* Add one file at a time. 
* commit the changes.
